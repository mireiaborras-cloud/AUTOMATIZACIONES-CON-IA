# AUTOMATIZACIONES-CON-IA

Aplicaciones web de un solo fichero que funcionan en el navegador con tu propia clave de IA.

- [Memoria I+D](memoria-id/): redacción asistida de memorias técnicas para convocatorias de I+D (IVACE+i y AVI).
- [Preguntas Test](preguntas-test/): banco de preguntas tipo test a partir de un libro en PDF, con el número de preguntas que elijas por tema.
