# AUTOMATIZACIONES-CON-IA

Aplicaciones web de un solo fichero que funcionan en el navegador con tu propia clave de IA.

- [Memoria I+D](memoria-id/): redacción asistida de memorias técnicas para convocatorias de I+D (IVACE+i y AVI).
- **Ejercicios tipo Duolingo para Formación Profesional**, en dos piezas que comparten el formato JSON del banco:
  - [Preguntas Test](preguntas-test/): el generador. Del libro (PDF, Word o texto) a un banco de ejercicios con el número que elijas por tema e imágenes del propio libro.
  - [Práctica](practica/): la app para los alumnos. Una sola app que carga cualquier banco de [`bancos/`](bancos/) según el enlace (`practica/?banco=NOMBRE`).
- [Presentación Oracle SQL](presentacion-oracle/): 10 diapositivas en HTML sobre la historia y el funcionamiento de Oracle, con estética de web universitaria (flechas ← → o deslizar para navegar).
